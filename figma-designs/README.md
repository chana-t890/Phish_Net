# Figma design extracts

This folder contains one markdown file per Figma design captured from the PhishNet file.

- [inbox-no-sidebar-light](inbox-no-sidebar-light.md) — Light-theme inbox experience with a header, email list pane, reading pane, attachment actions, and an avatar dropdown.
- [inbox-dark-nosidebar](inbox-dark-nosidebar.md) — Dark-theme inbox experience with the same layout as the light design but using dark surfaces and higher-contrast text.
- [tag-popover-light-nosidebar](tag-popover-light-nosidebar.md) — Light-theme tag popover / tagging experience embedded in a training-inbox shell.
- [tag-popover-dark-nosidebar](tag-popover-dark-nosidebar.md) — Dark-theme tag popover design that preserves the light variant structure while adopting dark surfaces.
- [ai-chat-light-nosidebar](ai-chat-light-nosidebar.md) — Light-theme AI chat experience with inbox navigation, assistant message states, and chat action surfaces.
- [ai-chat-dark-nosidebar](ai-chat-dark-nosidebar.md) — Dark-theme AI chat variant with the same structure as the light design and darker chrome.
- [summary-light-nosidebar](summary-light-nosidebar.md) — Light-theme training summary screen highlighting completion status, score, metrics, and reviewed emails.
- [summary-dark-nosidebar](summary-dark-nosidebar.md) — Dark-theme training summary screen that mirrors the light version with dark surfaces and high-contrast labels.
